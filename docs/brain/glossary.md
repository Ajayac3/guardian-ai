# Glossary
- **Full emergency** — "Help help help": audio (+ optional video) + GPS stream.
- **Soft alert** — "Guardian watch me": lighter monitoring; owner may cancel.
- **Cancel soft** — "Guardian I'm okay": ends a soft alert (owner-allowed).
- **Viewer** — the browser page an emergency contact opens via a shared link.
- **Heartbeat** — periodic device ping that keeps a session `active`.
- **Lost connection** — server state after heartbeats stop; not yet `ended`.
- **Magic-token grant** — scoped, account-less contact access to one session.
- **Recording indicator** — non-dismissible visible notice while recording.
- **Server-authoritative termination** — only the server (via contact / timeout /
  recovery) can end a session; the device cannot.
